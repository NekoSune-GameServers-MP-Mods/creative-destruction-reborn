# iOS client (future)

This folder is reserved for an independently developed iOS Reborn client.

No iOS `.ipa`, signed application, Apple developer provisioning profiles, entitlements, or iOS code has been supplied. An Android APK cannot be converted to an iOS IPA by renaming it.

For an eventual iOS build, store **your own source, build scripts and assets you have rights to distribute**, keep certificates/provisioning secrets out of Git, and use an appropriate macOS/Xcode CI build/signing process. Compatibility with the Reborn server and Steam/Android crossplay will require protocol testing and shared matchmaking/game-state replication.

Do not upload copyrighted game binaries or third-party signing material without authorisation.
